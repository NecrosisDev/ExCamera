# Changelog

## 0.1.0-beta3

First release with public source.

### Game versions and other mods
- No longer limited to one exact `Exanima.exe`. Every game function, global and vtable slot the mod uses (73
  in all) is found by its code signature at startup. If any is missing, the mod says which and changes
  nothing. Exanima 0.9.5.2g (Steam build 25803178) is the build tested in play; others run with a
  one-time "untested Exanima version" notice.
- Live hook check: the five hooks every game tick must reach are watched during play (game time, so pauses
  and menus don't count). On an untested build, or on top of another mod, a silent hook stops the mod and
  restores the game's camera.
- Another mod already hooking a function ExCamera uses is the player's decision: `[Compat] OtherHooks =
  ask | allow | refuse` (default `ask`: `ExCamera.exe` names the functions and asks). Before, the mod
  refused to start. It also no longer refuses because of editor-only functions it never uses.

### Fixes
- An unchecked read of the drag manager when placing a held object could crash the game if the drag ended
  in between.
- The status file escapes strings, so a level name with a quote in it no longer makes it invalid JSON.

### Changed
- The name is ExCamera everywhere players see it (notices, windows, the EMTK listing). Settings move to
  `Documents\ExCamera\first-person.ini`; the old `Documents\ExaniMate` file is copied over once.
- `ExanimaFirstPerson.dll` and the EMTK mod id `exanima-first-person` keep their names, so existing installs
  keep working.

### Source
- Game addresses are code signatures (`src/game_signatures.h`, generated by `tools/signatures.py`); struct
  offsets are named (`src/game_structs.h`). The mod is split into parts under `src/mod/`; the threads and
  the lock order are documented at the top of `src/mod/state.inl`.
- New suites: signature resolution and hook health, chaining onto another program's detour, the status
  writer. The tests refuse to build with `NDEBUG` (they check with `assert`).
- The scene walk (helmet, body wear, picks) uses a hash set instead of a quadratic duplicate check: same
  results, proven on random graphs against the old walk.
